# Data Structures & Algorithms in C

Modular implementations of fundamental data structures and algorithms in C[cite: 1].

## Modules

* **`binary-search-tree`**: Binary search tree (BST) implementation.
* **`doubly-linked-list`**: Doubly linked list.
* **`doubly-linked-ordered-list`**: Sorted doubly linked list.
* **`linked-queue`**: Dynamic queue (FIFO).
* **`linked-stack`**: Dynamic stack (LIFO).
* **`singly-linked-list`**: Singly linked list.
* **`singly-linked-ordered-list`**: Sorted singly linked list.
* **`static-ordered-list`**: Static array-based sorted list.
* **`static-queue`**: Static array-based queue.
* **`static-sequential-list`**: Static array-based list.
* **`static-stack`**: Static array-based stack.

## Repository Files

* **`CMakeLists.txt`**: Build configuration file.
* **`.gitignore`**: Git ignore rules.
* **`*.h`**: Public API headers.
* **`*.c`**: Implementation code.
* **`main.c`**: Test runner.
