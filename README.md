
Modular implementations of fundamental data structures and algorithms in C

## Repository Structure & Files

- `CMakeLists.txt`: Central build script that manages project compilation and subdirectories.
- `.gitignore`: Configured to exclude build artifacts, IDE settings, and binary files.
- `static-sequential-list`: Static array-based sequential list module.
-  `static-ordered-list`: Static array-based ordered list module.
  
  - `*.h`: Public ADT interface and function signatures.
  - `*.c`: Internal implementation logic.
  - `main.c`: Test runner and usage demonstration.
